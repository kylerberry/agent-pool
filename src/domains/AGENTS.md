# Domain Directory Instructions

`src/domains/` contains bounded-domain implementations. Create one directory per domain; each domain directory must contain a canonical `AGENTS.md` and a sibling `CLAUDE.md` containing only `@AGENTS.md`.

Before editing a domain, read its local `AGENTS.md` after root and docs instructions. Keep domain-specific, actionable learnings current during the CRAFTS S — Sharpen phase.

See `docs/raw/context/domain-driven-documentation-convention.md` and [[wiki/architecture/domain-driven-documentation|Domain-Driven Documentation]].
