# CRAFTS Phase Artifact Contract

## Summary

Canonical project decision or contract incorporated into the current supervisor-orchestrator design. Read the raw source for exact requirements and rationale.

## Elevated-risk security policy

Full-flow CRAFTS work is classified `low`, `medium`, or `high`; medium and high share the same controls. Elevated work receives an independent `security-and-hardening` plan review after C and before R, then a T review that maps every declared trust boundary to evidence, a finding, or non-applicability. This is a supplemental checkpoint, not a new phase or schema field. Reusable Tighten findings receive one Sharpen disposition: guidance update, owned follow-up, or documented non-generalizability.
