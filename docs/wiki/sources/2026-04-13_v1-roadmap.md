# Agent Pool v1 Roadmap

## Summary

The roadmap now prioritizes the proposed 17-node direct-task-first functional deployment: exact Z.ai qualification (GLM-5.2 active, GLM-5.3 release-completeness), dogfood, direct service, CRAFTS ledger/conductor, Tier-1/Tier-2 grading, governed failure/retry with budget, discovery, and recovery branches, ADR-015 PR assembly behind Gate 2, single-host operations baseline, and one release-convergence proof. Bootstrap routing is permitted for initial deployment; eval calibration, free-form intake, Graphify scheduling, agent-assisted probes, and ADR-037/038 are post-launch.

The fast-follow candidates include promoting local eval telemetry to a dual-layer design: run-scoped JSONL/manifests remain the recovery spool, while normalized telemetry is ingested idempotently into the orchestrator-owned SQLite audit store. Sanitized eval-candidate JSON remains the portable export rather than the durable source of truth.

A later target-repository external knowledge-provider track may support MCP or similar read-only systems only after controller onboarding approval, pinned versions, tool allowlists, scoped secrets/egress, phase grants, and provenance. Repository configuration must never auto-launch a provider; write-capable external sinks remain separately deferred.

Kyler approved P0 fast-follow hardening for target-repository codebase knowledge: content-level secret scanning/redaction, OS default-deny egress, OS read-only mount/sandbox isolation, and reproducible worker-image smoke attestation. These augment ADR-032's current baseline; they are not claimed as implemented controls.
