# Agent Pool v1 Roadmap

## Summary

Canonical project decision or contract incorporated into the current supervisor-orchestrator design. Read the raw source for exact requirements and rationale.

The fast-follow candidates include promoting local eval telemetry to a dual-layer design: run-scoped JSONL/manifests remain the recovery spool, while normalized telemetry is ingested idempotently into the orchestrator-owned SQLite audit store. Sanitized eval-candidate JSON remains the portable export rather than the durable source of truth.
